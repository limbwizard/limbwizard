Four more are private while I build them:

- **The Wizard's Ink.** Home of **Wizzy**, an experimental statically typed language whose compiler tracks effects, resources, and authority. It compiles and runs on three backends: a tree-walking interpreter, a bytecode VM, and a Cranelift native tier. This is the piece I care most about.
- **The Wizard's OS.** A from-scratch, capability-based Rust operating system for x86-64 and UEFI.
- **The Wizard's Conclave.** A local coding-agent orchestrator with a jailed sandbox, overseer, review, and auto-merge.
- **The Wizard's Courier.** A durable local job service. The specification and conformance corpus are written. No implementation exists yet.

The last three wait on the same Wizzy work: starting a process, opening a socket, and decoding JSON. Each one records that gate in its own decision log.

## Other things I've built

- **Bella.** A self-improving personal AI assistant on the Claude API: a 48-tool agent loop, hybrid-retrieval memory, real-time voice, and a loop that reviews its own weak conversations and opens PRs to fix its own code. A different model judges them, and I approve every merge.
- **limbserver.** A 47-service self-hosted platform with SSO, encrypted secrets, immutable backups, and observability. I hardened it with a 30-subagent LLM-driven penetration test that found and fixed a CVSS 9.3 vulnerability.
- **Hearthvale.** A 2D settlement-sim game in Godot/C#: 517 commits, ~48k lines, tests and CI, shipped solo in about four weeks.
