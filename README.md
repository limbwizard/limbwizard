## Other things I've built

- **[Bella](https://isaaclimb.com/projects/bella.html).** A personal AI assistant with local storage and retrieval, scoped tools, and real-time voice. Claude handles conversation by default; selected prompt context goes to the hosted provider. Local Ollama handles bounded utility work. Streaming speech recognition uses Parakeet, with a batch Whisper fallback; speech output supports hosted voices and local Kokoro.
- **limbserver.** A 47-service self-hosted platform with SSO, encrypted secrets, immutable backups, and observability. I hardened it with a 30-subagent LLM-driven penetration test that found and fixed a CVSS 9.3 vulnerability.
- **[Wizards Helm](https://isaaclimb.com/projects/wizards-helm.html).** A Tauri desktop operations wall for AI coding sessions and a persistent bot fleet: live sessions, hosted terminals, decisions, goals, and replay across monitors. Working, private.
- **[Git Gud](https://isaaclimb.com/projects/git-gud.html).** A local-first Android strength and health app with on-device workout generation, set logging, progression, training blocks, portable backups, and optional Health Connect. Private; no public store release.
- **[Smoke Rising](https://isaaclimb.com/projects/smoke-rising.html).** An offline, single-player settlement simulation in Godot/C#, with autonomous villagers, direct unit and army control, age progression, and local JSON mods. Playable from private source. Commercial release acceptance is still open.
